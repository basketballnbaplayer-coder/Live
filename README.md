# StreamHub — v6.0 (юридический блок + бот)

## Новое в v6.0

**Юридический блок**
- Privacy Policy и Terms of Service — реальные тексты, сгенерированные для сайта
  (ZytroLive), встроены прямо в код (`src/components/legal/`).
- Открываются в **модальном окне** — клик по ссылке НЕ уводит со страницы
  регистрации и не стирает то, что уже введено в форму.
- Внизу главной страницы — футер со ссылками Privacy/Terms/Support.

**Обязательное согласие при регистрации**
- Без галочки "I agree to..." регистрация не пройдёт — чекбокс подсвечивается
  красной рамкой и текстом ошибки.
- Текст ссылок ("Terms of Service" / "Privacy Policy") кликабелен — открывает
  соответствующий документ.

**Живая проверка username**
- Пока печатаешь имя при регистрации — сайт сам проверяет, свободно ли оно
  (значок ✓/✗ прямо в поле, с задержкой в реальном времени).

**Пример бота с access-токеном**
- `bot-example/` — рабочий Node.js-скрипт: логинится как обычный аккаунт
  StreamHub, получает `access_token`, и на его основе может писать в чат /
  делать что угодно, что разрешено этому аккаунту (по тем же правилам RLS,
  что и у обычных людей).

## Настройка
Ничего нового в SQL добавлять не нужно — все таблицы уже были готовы с v5.0.

```
npm install
npm run dev
```

Для бота:
```
cd bot-example
npm install
cp .env.example .env   # впиши логин/пароль бот-аккаунта
node login.js
```
